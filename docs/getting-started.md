# Getting started

```bash
npx create-zolt@latest my-app
cd my-app
zolt dev
```

Visit http://localhost:3000. If your shell does not resolve project-local binaries directly, use `npx zolt dev`, `npm run dev`, or `pnpm zolt dev`. Edit `app/pages/HomePage.tsx`; Vite applies the update immediately. Use `npx zolt build` to produce `dist` and `npx zolt start` to serve that build.
